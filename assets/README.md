# VRTon Website - Asset Directory

This directory contains all the assets for the VRTon website.

## Required Assets

### Logo
- `logo.webp` - Main VRTon logo (recommended size: 180x180px or higher resolution)

### VRChat Badge
- `vrchat-placeholder.webp` - Image for the VRChat experience badge

### Event Images (3 images per year)
**2023 Event:**
- `event-2023-1.webp`
- `event-2023-2.webp`
- `event-2023-3.webp`

**2024 Event:**
- `event-2024-1.webp`
- `event-2024-2.webp`
- `event-2024-3.webp`

**2025 Event:**
- `event-2025-1.webp`
- `event-2025-2.webp`
- `event-2025-3.webp`

## Image Specifications

- **Logo**: WebP format with transparent background
- **VRChat Badge**: Landscape image
- **Event Images**: Landscape orientation recommended (4:3 or 16:9 aspect ratio)
- **Format**: WebP
- **Quality**: High resolution for retina displays

## Notes

The website includes automatic placeholder generation if images are missing, but please replace them with actual images for production use.
